# INVEMOTO

Sistema multiplataforma para la gestion de inventario y ventas de accesorios para motocicletas.

## Estructura del proyecto

- `backend/` - API REST y logica de negocio
- `analytics/` - Servicio de analitica predictiva
- `frontend/` - Aplicacion web
- `mobile/` - Aplicacion movil
- `database/` - Scripts y configuracion de base de datos
- `docker/` - Configuracion relacionada con Docker
